## 中文

修复市场结果在 Agent 工具里的 JSON 兼容问题。

- `market_search_mcp` / `market_search_skills` 的返回值不再包含 `undefined` 字段（registry 条目中可选的仓库、网站、环境变量默认值现在直接省略），工具调用重新可用。
- 回归测试新增 JSON round-trip 断言，防止同类问题。

## English

Fix the JSON compatibility of market results in agent tools.

- `market_search_mcp` / `market_search_skills` no longer return `undefined` fields (optional repository, website and environment-variable defaults are simply omitted), so the tools work again.
- A JSON round-trip assertion was added to the market tests to prevent regressions.
