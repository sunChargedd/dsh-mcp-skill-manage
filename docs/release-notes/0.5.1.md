## 中文

市场功能的稳定性修复。

- MCP Registry 的 `version=latest` 查询偶尔超时；现在会自动降级为无过滤列表，并按 registry 返回的 latest 标记去重，不再直接报错。
- 市场搜索结果缓存 5 分钟，重复搜索即时返回；首次查询仍可能需要几秒。
- 主查询超时从 18 秒降到 6 秒，降级查询 15 秒，整体等待更可控。

## English

A reliability fix for the market feature.

- The MCP registry's `version=latest` query occasionally times out; search now falls back to the unfiltered list, keeps the entry flagged as latest per server name and no longer fails outright.
- Market searches are cached for five minutes, so repeated searches return instantly while the first one may still take a few seconds.
- The primary attempt now times out after 6 seconds (15 for the fallback), keeping total waiting predictable.
