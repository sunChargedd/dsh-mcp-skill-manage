## 中文

首个公开开源版本。左侧栏新增「MCP 与技能」入口，一个页面管理多个 agent 工具的 skill 与 MCP 服务器。

**Skills**
- 卡片网格 + 全宽详情页，搜索、按工具过滤，返回保留筛选
- 完整编辑 frontmatter 与 Markdown 正文；支持目录式与扁平 skill
- 跨工具共享：勾选工具自动创建符号链接，单一主副本
- 卡片快捷操作：打开主副本位置、删除（内联确认）
- zip 导入/导出（保留 references/scripts 等目录）
- 备份与恢复：删除前自动快照，可恢复到任意可写根目录

**MCP**
- 表格视图，行内启停 / 删除 / 打开配置 / 测试连接
- 支持 DSH profile patch、Claude、Codex、Cursor、Windsurf 及检测到的更多工具
- stdio 与 HTTP/SSE；跨工具复制；env/headers 默认打码
- 真实 MCP 握手体检查看工具数量、延迟、server 版本

**其它**
- 项目管理、自定义目录/配置文件、诊断
- Agent 工具 `mcp_skill_manager`，与页面共用同一 Host action 层
- 零运行时依赖；数据层 / Host action / zip 与探针 / 无头渲染测试

安装：`plugin_manager action=install_bundle target=<仓库目录>`，然后刷新页面。

## English

First public, open-source release: a DSH sidebar page that manages skills and MCP servers across DSH, Claude Code, Codex, Cursor, Windsurf and other detected agent tools.

**Skills** — card grid + full-width detail pages, search and per-tool filters that survive navigation; complete frontmatter and Markdown body editing; directory and flat skills; cross-tool sharing through relative symlinks; quick actions (reveal, delete with inline confirm); zip import/export; write-ahead backups with restore.

**MCP** — table view with inline enable/disable, delete, reveal and test connection; DSH profile patch, Claude, Codex, Cursor, Windsurf and more; stdio plus HTTP/SSE; cross-tool copy; masked secrets; real MCP handshake health check with tool count, latency and server version.

**Also** — project tracking, custom skill directories and MCP config files, diagnostics, and the `mcp_skill_manager` agent tool sharing the same Host action layer. Zero runtime dependencies, with data-layer, action, zip/probe and headless-render test suites.

Install with `plugin_manager action=install_bundle target=<repo path>`, then refresh the page.
