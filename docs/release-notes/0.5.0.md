## 中文

新增「市场」标签页：在插件里直接发现并安装 skill 和 MCP。

- **Skills 市场**：搜索 [skills.sh](https://skills.sh) 的 Agent Skill 索引，从对应 GitHub 仓库下载完整 skill 目录并安装到任意可写 skill 根目录（自动避让重名，不覆盖）。
- **MCP 市场**：搜索官方 [Model Context Protocol Registry](https://registry.modelcontextprotocol.io)，优先使用 remote HTTP 端点，否则按 npm/pypi 包生成 `npx`/`uvx` stdio 配置；必填环境变量以空值占位并在结果里提示。
- 同一个页面切换来源、搜索、选择安装目标；只在主动搜索/安装时联网。
- Agent 工具同步新增 `market_search_skills` / `market_install_skill` / `market_search_mcp` / `market_install_mcp`。
- 可选设置 `GITHUB_TOKEN` 提高 GitHub API 速率限制。
- 新增假网络测试 `scripts/test-market.mjs`，CI 独立执行。

## English

A new Market tab for discovering and installing skills and MCP servers inside the plugin.

- **Skills market**: search the [skills.sh](https://skills.sh) Agent Skill index, download the full skill directory from its GitHub repository and import it into any writable skills root (name conflicts are renamed, never overwritten).
- **MCP market**: search the official [Model Context Protocol Registry](https://registry.modelcontextprotocol.io); remote HTTP endpoints are used directly, otherwise npm/pypi packages are mapped to `npx`/`uvx` stdio config with required environment variables pre-filled as placeholders and reported.
- Switch source, search and choose the install target on one page; network access happens only when you search or install.
- New agent-tool actions: `market_search_skills`, `market_install_skill`, `market_search_mcp`, `market_install_mcp`.
- Optional `GITHUB_TOKEN` raises the GitHub API rate limit.
- New fake-network test suite `scripts/test-market.mjs`, run as its own CI step.
