## 中文

一次以"减少点击"为目标的功能更新。

- **全文搜索**：Skills 工具栏新增「搜索正文」，直接搜 `SKILL.md` 内容；卡片显示命中片段与命中次数。同时新增 Host action `skill/search` 和 Agent 工具 `search_skills`。
- **批量操作**：列表进入「批量」多选后，可一次共享到某个 skill 根目录、导出为一个 zip、或删除（内联二次确认）。
- **新建模板**：skill 提供空白 / 代码审查 / 文档撰写 / 问题排查模板；MCP 提供 Context7 / Filesystem / GitHub / SQLite / Playwright 模板，一键填好命令或 URL 与 env 占位。
- **MCP 体检结果增强**：详情页在体检通过后直接列出该 server 暴露的全部工具。

测试：action 测试新增全文搜索与 `search_skills`；渲染测试新增模板预填、批量删除、正文搜索开关。

## English

A release focused on fewer clicks.

- **Full-text skill search**: a new "Body" toggle searches inside `SKILL.md` content and shows matching snippets plus hit counts on the cards. Also adds the `skill/search` Host action and the `search_skills` agent tool.
- **Bulk operations**: enter Select mode, then share the selected skills to a root, export them as one zip, or delete them with a single inline confirmation.
- **Starter templates**: skills start from Blank / Code review / Documentation / Debugging; MCP servers from Context7 / Filesystem / GitHub / SQLite / Playwright, prefilled with commands, URLs and env placeholders.
- **Health results**: MCP detail pages list every tool reported by the last successful health check.

Tests: the action suite covers full-text search and `search_skills`; the render suite covers template prefill, bulk delete and the body-search toggle.
