## 中文

维护与发布流程升级。

- **Release 自动化**：推送 `v*` tag 后，GitHub Actions 自动从 `CHANGELOG.md` 截取该版本段落并创建 GitHub Release；支持 `docs/release-notes/<version>.md` 覆盖为中英双语文案
- **自建插件市场索引**：`npm run market:build` 生成 format-1 索引（git source，固定 commit），已用 DSH 官方 validator 验证；用户可在 Settings → Plugins → Discover → Index sources 添加：
  `https://raw.githubusercontent.com/sunChargedd/dsh-mcp-skill-manager/main/market/index.json`
- **上架指南**：`docs/PUBLISHING.md` 说明自建索引、Awesome DSH Plugin 收录、npm 发布三条路径；`market/awesome-plugin.yml` 为可直接提交的条目模板

> 注意：npm 上的 `dsh-mcp-skill-manager` 已被其他作者占用，进入默认市场前需要换一个可用包名（推荐 npm scope）。

## English

Release and distribution tooling.

- **Automated releases**: pushing a `v*` tag makes GitHub Actions publish a GitHub Release from that version's `CHANGELOG.md` section; `docs/release-notes/<version>.md` can override it with curated bilingual notes.
- **Self-hosted market index**: `npm run market:build` generates a format-1 index (git source pinned to a commit), validated with DSH's own validator. Add it under Settings → Plugins → Discover → Index sources:
  `https://raw.githubusercontent.com/sunChargedd/dsh-mcp-skill-manager/main/market/index.json`
- **Publishing guide**: `docs/PUBLISHING.md` covers self-hosted indexes, the Awesome DSH Plugin listing and npm publication; `market/awesome-plugin.yml` is the ready-to-submit entry.

> Note: the npm name `dsh-mcp-skill-manager` is taken by another author, so the default Discover market requires renaming the package (an npm scope is recommended).
