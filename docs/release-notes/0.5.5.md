## 中文

补充 DSH 兼容性声明，避免在错误版本上安装后报错。

- `package.json` 声明 `engines.dsh: ">=0.2.1-rc.3 <0.3.0"`（开发与实机验证版本为 DSH 0.2.1-rc.3）。
- DSH 安装/启动前会做兼容性检查；版本不满足时阻止加载并提示，而不是运行后崩溃。
- Host 激活时额外检查 `webServer.register`，缺失时抛出明确错误。
- 自建市场索引的版本条目带上 `engines.dsh`，Discover 可展示兼容性要求。
- README（中/英）新增兼容性表：DSH 版本、Node >=20、平台与用到的扩展点。

## English

Explicit DSH compatibility metadata so installs on unsupported versions fail clearly instead of crashing.

- `package.json` declares `engines.dsh: ">=0.2.1-rc.3 <0.3.0"` (developed and verified on DSH 0.2.1-rc.3).
- DSH checks compatibility before installing or loading the plugin and refuses it with a clear message instead of failing at runtime.
- The Host additionally validates `webServer.register` during activation and throws an explicit error when it is missing.
- The self-hosted market index version entry carries the same requirement, so Discover can surface it.
- Both READMEs now include a compatibility table: DSH range, Node >=20, verified platform and the DSH extension points used.
