## 中文

首个可发布到 npm 的版本，项目正式更名为 **dsh-mcp-skill-manage**。

- **改名**：旧的 npm 包名 `dsh-mcp-skill-manager` 已被其他作者占用，因此仓库、包名、client 模块 id、loader 行统一改为 `dsh-mcp-skill-manage`
- **npm 就绪**：`package.json` 已设置 `private: false` 与 `publishConfig.access: public`，`npm publish` 即可安装
- **Release 自动化**：推送 `v*` tag 自动从 `CHANGELOG.md`（或 `docs/release-notes/<version>.md`）创建 GitHub Release
- **自建市场索引**：`market/index.json` 指向本版本 commit，可直接加入 Discover 索引源

安装（npm 发布后）：

```text
plugin_manager action=install_bundle target=dsh-mcp-skill-manage@<version>
```

## English

First npm-publishable release, renamed to **dsh-mcp-skill-manage**.

- **Rename**: the npm name `dsh-mcp-skill-manager` was already taken, so the repository, package name, client module id and loader row are now `dsh-mcp-skill-manage`.
- **npm ready**: `private: false` plus `publishConfig.access: public`, so `npm publish` produces an installable package.
- **Automated releases**: a pushed `v*` tag creates a GitHub Release from `CHANGELOG.md` (or curated `docs/release-notes/<version>.md`).
- **Self-hosted market index**: `market/index.json` pins this version's commit and can be added as a Discover index source.

Install (after the npm publish):

```text
plugin_manager action=install_bundle target=dsh-mcp-skill-manage@<version>
```
