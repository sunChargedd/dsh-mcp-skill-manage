## 中文

MCP 市场可用性修复。

- 不再使用 registry 上经常超时的 `version=latest` 过滤；改为取无过滤列表，按 latest 标记与版本号选出每个 server 的最新条目。
- registry 不可达时自动回退到内置常用服务器列表（Context7、Filesystem、GitHub、SQLite、Playwright、Memory、Sequential Thinking、Brave Search、PostgreSQL、Fetch），并在页面显示提示。
- 查询超时从 15 秒降到 8 秒，失败后立即给出可用结果；搜索缓存保留。

## English

MCP market availability fix.

- Drops the frequently slow `version=latest` registry filter; search now fetches the unfiltered list and keeps the newest entry per server by latest flag and version.
- When the registry is unreachable, search falls back to a built-in list of popular servers (Context7, Filesystem, GitHub, SQLite, Playwright, Memory, Sequential Thinking, Brave Search, PostgreSQL, Fetch) and shows a warning in the UI.
- The registry timeout is 8 seconds, so failures surface quickly with usable results; search caching stays.
