## 中文

修复市场结果里残留的 `undefined` 字段。

- registry 条目中可选的环境变量默认值现在直接省略，不再以 `undefined` 出现；`market_search_mcp` / `market_search_skills` 返回真正可序列化的 JSON。
- 测试里的 JSON round-trip 断言覆盖该字段。

## English

Remove the remaining `undefined` field from market results.

- Optional environment-variable defaults in registry entries are omitted instead of being stored as `undefined`, so `market_search_mcp` / `market_search_skills` return genuinely serializable JSON.
- The JSON round-trip assertion in the tests covers this field.
